# AI Business Assistant SaaS

A multi-tenant AI customer-support platform.

## Goal

Allow businesses to upload:
- PDF
- DOCX
- TXT
- CSV
- XLSX

and create an AI assistant that answers customers using approved business knowledge.

## Planned Stack

Frontend:
- Next.js
- TypeScript
- Tailwind CSS

Backend:
- FastAPI
- Python

Database:
- PostgreSQL
- pgvector

Automation:
- n8n

AI:
- Ollama / OpenAI / Anthropic

Development:
- Docker Compose
